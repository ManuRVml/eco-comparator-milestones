# BenchHub · Seguimiento del MVP

Aplicación de seguimiento del MVP BenchHub (Next.js App Router + TypeScript + Tailwind + libSQL/Drizzle).

- `app/` – código de la aplicación (sin datos del proyecto; los datos se importan desde los archivos del plan, que no forman parte de este repositorio).
- `docs/05_SPEC_APP_SEGUIMIENTO.md` – especificación funcional y técnica de la aplicación.
- `docs/03_ESTANDAR_APIS.md` – estándar de APIs.

Instalación, importación y despliegue: ver `app/README.md` y `app/DEPLOY.md`.
